# Showcase production standards

These documents define the shared *quality bar*, not a shared visual aesthetic.

## Starting a new brand
1. Read `AGENTS.md` and `standards/workflow.md`.
2. Create a branch from the intended baseline, preserving ATELIER (`main`) and Serein (`serein-pilates`).
3. Make `brands/<slug>/brief.md` from `brands/BRIEF_TEMPLATE.md`.
4. Compare concept direction against `brands/creative-matrix.md`. Fill unknowns honestly.
5. Implement and run static QA per `standards/quality-gates.md`.
6. Seek design approval based on static screenshots. Video is a separate, explicit request.

## Documents
- `design-system.md`: adaptive rules and design tokens
- `anti-ai-slop.md`: negative patterns and alternatives
- `imagery.md`: purposeful imagery and sourcing
- `quality-gates.md`: objective checks + subjective review
- `workflow.md`: stage gates and repo/branch hygiene

## Agent skills
- `brand-strategy`: defines a concept that deserves a standalone project
- `editorial-art-direction`: translates concept into photography and layout direction
- `website-design`: implements semantic responsive UI
- `visual-qa`: reviews browser screenshots
- `showcase-export`: creates presentation assets on explicit request only

Capture tooling may already exist. Its presence is never authorization to render a video.
