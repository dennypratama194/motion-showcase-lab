# Website design
1. Read brand brief and `standards/design-system.md`.
2. Inspect active branch, Next.js local documentation and existing scripts before editing.
3. Define per-brand design tokens: semantic colors, type roles, spacing, grid, focus states, motion.
4. Build content-first semantic sections with genuine nav/CTA behavior and responsive images.
5. Use 1440 12-column/100 margin/24 gutter reference; consciously adapt tablet/mobile.
6. Review 1440, 768 and 390 layouts. Ensure keyboard, reduced motion and no overflow.
7. Hand off to visual-qa. Never trigger `npm run capture` without explicit video request.
Output: working website, decisions, tested breakpoints, known limits.
