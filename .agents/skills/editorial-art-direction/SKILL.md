# Editorial art direction
1. Read brand brief, `standards/imagery.md`, and `standards/anti-ai-slop.md`.
2. Create a shot list with role, subject, lens/lighting, crop, mobile crop, source and rights.
3. Define a dominant compositional idea and varied secondary rhythms; explain what each image communicates.
4. Set the visual palette and type pairing intentionally. Avoid recurring default brand formulas.
5. Check photo cohesion, realism, authenticity, contrast and performance. Do not invent client facilities or participants.
6. Record art-direction decisions in the brand brief before website implementation.
Output: mood/direction notes, shot list and layout image map; never a reel.
